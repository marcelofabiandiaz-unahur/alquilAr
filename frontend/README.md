# Frontend AlquilAR

Aplicación React con TypeScript, Vite y TailwindCSS. Los componentes están en `src/` como `.tsx` y los módulos sin JSX como `.ts`.

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm run typecheck
npm run lint
npm run build
```

El build ejecuta el chequeo estricto de TypeScript antes de generar los archivos de Vite.
